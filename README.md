# 🖋️ Sosh_Ink Tattoo Studio

Welcome to **Sosh_Ink**, a modern tattoo studio website designed to showcase custom artwork, artist portfolios, bookings, and tattoo inspiration.

## 📌 About

Sosh_Ink is a tattoo studio focused on high-quality custom tattoos, creativity, and professional client experiences. This website allows clients to:

- View tattoo portfolios
- Explore tattoo styles
- Learn about the studio
- Book appointments
- Contact the shop easily
- Browse pricing and FAQs

## 🎨 Features

✅ Modern tattoo shop design  
✅ Artist portfolio/gallery  
✅ Appointment booking system  
✅ Contact form  
✅ Mobile-friendly responsive layout  
✅ Tattoo style showcase  
✅ Clean and professional UI

## 🛠️ Built With

- HTML5  
- CSS3  
- JavaScript
